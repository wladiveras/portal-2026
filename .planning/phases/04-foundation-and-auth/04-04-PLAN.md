<objective>
Build the authorization plumbing shared by every dashboard page: global auth guard, per-page role guard, and a reactive `useRole()` composable backed by Supabase.
</objective>

<tasks>

<task type="auto">
  <name>Task 1: Types</name>
  <files>app/types/auth.ts</files>
  <action>Export `type UserRole = 'admin' | 'editor' | 'viewer'` and `interface Profile { id: string; role: UserRole; full_name: string | null; disabled: boolean }`.</action>
</task>

<task type="auto">
  <name>Task 2: Global auth middleware</name>
  <files>app/middleware/auth.global.ts</files>
  <action>`defineNuxtRouteMiddleware` that skips non-`/dashboard` and `/login` / `/confirm`. Uses `useSupabaseUser()`; if null, `return navigateTo({ path: '/login', query: { redirect: to.fullPath } })`.</action>
</task>

<task type="auto">
  <name>Task 3: useRole composable</name>
  <files>app/composables/useRole.ts</files>
  <action>Fetch profile on first call (cached via `useState('profile')`): `select id, role, full_name, disabled from profiles where id = user.id`. Return `{ profile, isAdmin, isEditor, isViewer, can }` where `can('manage_users')` maps to `isAdmin`, `can('edit_leads')` = admin|editor, etc.</action>
</task>

<task type="auto">
  <name>Task 4: Named role middleware</name>
  <files>app/middleware/role.ts</files>
  <action>`defineNuxtRouteMiddleware((to) => { const required = to.meta.role as UserRole | undefined; if (!required) return; const { profile } = useRole(); if (!profile.value || profile.value.role !== required) throw createError({ statusCode: 403 }) })`. Support array of roles.</action>
</task>

</tasks>

</verification>
